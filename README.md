# Alien Invasion

## Video Presentation

https://www.youtube.com/watch?v=b7NA5NqYfYU

## Overview

Alien Invasion is an arcade-style game developed in Python using Pygame. The player controls a spaceship that moves up and down on the left side of the screen and shoots bullets horizontally to destroy waves of invading aliens. The objective is to eliminate as many aliens as possible while avoiding collisions and keeping the aliens from reaching the edge behind the ship.

## Track

I chose **Track 1: Custom Game Mechanics**.

## Orientation

I modified the original game by changing the ship's position and movement. Instead of starting at the bottom of the screen and moving left and right, the ship starts on the left side and moves up and down. The bullets also fire horizontally from the ship's new position, and the alien fleet was adjusted to match the new gameplay.

## Features

* Ship moves up and down on the left side.
* Bullets fire horizontally.
* Alien fleet moves horizontally.
* Laser and ship collision detection.
* Play button and game states.
* HUD displaying score, high score, and lives.
* Mouse cursor is hidden during gameplay.
* Asset paths use `pathlib`.
